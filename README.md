# Employee Skill Assessment & Job Role Recommendation System

A NumPy-only mini project that evaluates eight employees across four technical skills and recommends suitable job roles using weighted matrix multiplication.

## Requirements

- Python 3.8+
- NumPy

Install the dependency:

```bash
pip install -r requirements.txt
```

## Run

```bash
python employee_skill_assessment.py
```

## Skills assessed

1. Python Programming
2. SQL and Databases
3. Machine Learning
4. Communication Skills

## Job roles

- Data Analyst
- Machine Learning Engineer
- Technical Trainer

## Project tasks

1. Employee skill data management using NumPy arrays, shape, flattening, reshaping and indexing.
2. Job role suitability analysis using matrix multiplication (`np.matmul`).
3. Performance-based bonus calculation using NumPy broadcasting.
4. Machine Learning training simulation using `np.clip`.
5. Random performance simulations using `np.random.rand` and `np.random.randn`.
6. Individual E03 evaluation using `np.dot`.
7. Employee-role recommendations and business insights using NumPy functions.

## Technology

- Python
- NumPy

**Note:** Pandas, Scikit-learn and other data-analysis libraries are not used.
